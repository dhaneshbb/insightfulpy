# InsightfulPy Documentation

InsightfulPy v0.2.0 - Python toolkit for exploratory data analysis with visualization and statistical functions.

## Key Features

- Statistical summaries for numerical and categorical data
- Data quality checks (missing values, outliers, mixed 
types)
- Batch visualization for large datasets
- Individual column analysis with plots
- Multi-dataset comparison tools
- Environment detection (Jupyter and terminal)
- Constants-driven configuration
- Type hints and documentation
